# Chrome Keyboard Shortcuts

## Windows & Linux Shortcuts

### Tab & Window Shortcuts

| Action                                                               | Shortcut                                       |
| -------------------------------------------------------------------- | ---------------------------------------------- |
| Open a new window                                                    | `Ctrl + N`                                     |
| Open a new window in Incognito mode                                  | `Ctrl + Shift + N`                             |
| Open a new tab, and jump to it                                       | `Ctrl + T`                                     |
| Reopen previously closed tabs in the order they were closed          | `Ctrl + Shift + T`                             |
| Jump to the next open tab                                            | `Ctrl + Tab` or `Ctrl + PgDn`                  |
| Jump to the previous open tab                                        | `Ctrl + Shift + Tab` or `Ctrl + PgUp`          |
| Jump to a specific tab                                               | `Ctrl + 1` through `Ctrl + 8`                  |
| Jump to the rightmost tab                                            | `Ctrl + 9`                                     |
| Open your home page in the current tab                               | `Alt + Home`                                   |
| Open the previous page from your browsing history in the current tab | `Alt + Left arrow`                             |
| Open the next page from your browsing history in the current tab     | `Alt + Right arrow`                            |
| Close the current tab                                                | `Ctrl + W` or `Ctrl + F4`                      |
| Close the current window                                             | `Ctrl + Shift + W` or `Alt + F4`               |
| Minimize the current window                                          | `Alt + Space` then `N`                         |
| Maximize the current window                                          | `Alt + Space` then `X`                         |
| Quit Google Chrome                                                   | `Alt + F` then `X`                             |
| Move tabs right or left                                              | `Ctrl + Shift + PgUp` or `Ctrl + Shift + PgDn` |
| Turn on full-screen mode                                             | `F11`                                          |
| Turn off full-screen mode                                            | `F11` or press and hold `Esc`                  |

## Tips

- **Windows/Linux**: Keyboard navigation is enabled according to system default settings.
- **Mac**: Press `⌘ + F7` to move keyboard focus to text boxes and list items.
- When a tab group is collapsed, you can only select the group and not individual tabs within it.

## Special Notes

### Opening Tab Group Menu on Windows:

1. Open Chrome
2. Press `F6` to move focus to tabs
3. Press `Tab` (forward) or `Shift + Tab` (backward) to move to specific tabs
4. Press `Menu` key to open tab group menu
5. Menu selection: Use arrow keys to navigate and press `Enter` to select

### Using VoiceOver on Mac:

1. Turn on VoiceOver and open Chrome
2. Press `Tab` to move to tab selection
3. Press `Tab` (forward) or `Shift + Tab` (backward) to move to specific tabs
